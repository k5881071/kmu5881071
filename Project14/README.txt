데이터 크기 증가에 따른 삽입 정렬과 쉘 정렬의 비교 횟수 변화
삽입정렬:크기가 2배 커지면 비교횟수가 기존의 4배에 가까운 수치폭으로 증가한다.
쉘정렬:크기가 2배 커지면 비교횟수가 기존의 2.39배에 가까운 수치폭으로 증가한다.

삽입 정렬과 쉘 정렬의 성능 차이
데이터의 수를 5, 10, 25, 50 등을 추가하여 실행해본 결과, 비교하는 데이터가 커질수록 쉘정렬이 삽입정렬보다 효율적이다. 데이터 수가 7,9,14,15일 때 삽입정렬이 쉘정렬보다 효율적이다.

쉘 정렬의 기본 간격과 Knuth 수열의 성능 차이
기본 간격보다 Knuth 수열의 성능이 보다 효율적이다.

간격 수열이 쉘 정렬의 성능에 영향을 미치는 이유
수열의 간격이 서로소에 가까울수록 이미 비교한 데이터를 비교하는 행위의 발생이 적어서 효율적이게 된다.
