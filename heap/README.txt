데이터 크기 증가에 따른 세 정렬 알고리즘의 비교 횟수 변화
데이터 크기가 2배가 될수록 2.2배에 가깝게 증가하였다.
 
힙 정렬, 병합 정렬, 퀵 정렬의 실행시간 차이
퀵 정렬이 가장 적은 실행시간을 보였으며, 데이터의 크기가 16250을 넘기기 전에는 병합 정렬의 실행 시간이 가장 길었으나 데이터의 크기가 16251 이상이 되면 힙 정렬의 실행 시간이 가장 길었다.

세 정렬 알고리즘의 메모리 사용량 차이
힙 정렬이 가장 적은 메모리를 사용하였으며, 병합 정렬이 가장 많은 메모이를 사용하였다.

퀵 정렬의 피벗 선택 방법에 따른 성능 차이
첫 번째 원소 선택:실행속도가 빠르고 메모리 사용량이 가장 크다.
무작위 원소 선택:랜덤성이 강하여 일정한 경향을 보이지 않는다.
세 원소의 중앙값 선택: 실행속도가 가장 빠르고, 데이터가 커질수록 메모리 사용량이 가장 적어진다.

세 정렬 알고리즘의 시간 복잡도 및 공간 복잡도 비교
힙 정렬은 공간 복잡도가 가장 작으며, 데이터 크기에 따라 일정한 시간 복잡도를 가진다.
병합 정렬은 공간 복잡도가 가장 크지만, 데이터 크기에 따라 일정한 시간 복잡도를 가진다.
퀵 정렬은 피벗 지정 방식과 정렬 정도에 따라 시간 복잡도와 공간 복잡도가 가장 클 수 있다.

메모리 사용량의 측정 방법과 계산 기준
계산 기준으로는 원본 데이터 배열이 사용하는 메모리를 제외하고 실행중 사용하는 메모리만을 계산하였다.
힙 정렬은 함수가 사용하는 메모리를 계산하여 구하였다.
병합 정렬은 함수가 사용하는 메모리에 임시배열의 용량을 합하여 구하였다.
퀵 정렬은 함수가 사용하는 메모리를 계산하여 구하였다.
