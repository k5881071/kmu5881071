데이터 크기 증가에 따른 병합 정렬과 퀵 정렬의 비교 횟수 변화
두 정렬모두 데이터 크기가 2배가 되면 비교횟수가 약 2.20배 증가하나, 병합 정렬 쪽이 변동폭이 작다.

두 정렬 알고리즘의 실행시간 차이
퀵 정렬이 병합 정렬보다 실행시간이 짧다.

두 정렬 알고리즘의 메모리 사용량 차이
병합 정렬의 메모리 사용량이 퀵 정렬보다 크다.

퀵 정렬의 피벗 선택 방법에 따른 성능 차이
첫 번째 원소 선택:실행속도가 빠르고 메모리 사용량이 가장 크다.
무작위 원소 선택:랜덤성이 강하다.
세 원소의 중앙값 선택: 실행속도가 가장 빠르고, 메모리 사용량이 가장 적다.

병합 정렬과 퀵 정렬의 시간 복잡도 및 공간 복잡도 차이
시간 복잡도에서는 병합 정렬이 효율적이나 공간복잡도에서는 퀵 정렬이 효율적이다.

메모리 사용량의 측정 방법과 계산 기준
병합 정렬은 임시 배열의 크기를 크기를 구한 후 재귀 스택 최대 사용량을 합해서 구하였고, 퀵정렬을 재귀 스택 최대 사용량을 구해서 측정했습니다.
재귀 스택의 최대 사용량은 매 재귀 호출에서 지역 변수의 주소를 정렬 시작 시점의 주소와 비교해 그 차이의 최댓값을 기록하여 도출했습니다.
